# 🛒 TechStore - E-Commerce Landing Page

## 📌 Project Overview

TechStore is a responsive E-Commerce Landing Page developed using HTML, CSS, and JavaScript. The website provides users with a modern shopping experience through an attractive interface, responsive design, and interactive features.

This project was created as part of a Front-End Web Development assignment and demonstrates the implementation of modern web design principles and client-side functionality.

---

### Home Page
- Responsive Navigation Bar
- Hero Section

## ⚙️ How to Run

### Method 1

1. Download the project files.
2. Open the project folder.
3. Double-click `index.html`.

### Method 2

1. Open the project in VS Code.
2. Install Live Server Extension.
3. Right Click on `index.html`.
4. Select **Open with Live Server**.
